# Promptlar

Bu papkadagi fayllar — Claude'ga **ko'chirib qo'yish** uchun tayyor promptlar.
Har bir fayl to'liq nusxalanadi: ichida izoh yoki sarlavha yo'q, faqat promptning o'zi.

| Fayl | Nima uchun | Qanday ishlatiladi |
|---|---|---|
| `admin-panel-dizayn-prompti.md` | Admin panelning bosiladigan UI dizayni (10 ta ekran) | Faylni to'liq nusxalab Claude'ning dizayn dasturiga qo'yish. Iloji bo'lsa `docs/prototip/admin-panel.html` faylini ham biriktirish — shunda bosh panel noldan emas, tayyor holatdan davom etadi |

Promptlar mustaqil yozilgan: CLAUDE.md boshqa dasturda ochilmaydi, shuning uchun kerakli
ma'lumot (ranglar, hisob qoidalari, ekranlar tavsifi) prompt ichida takrorlangan.
**CLAUDE.md dagi qaror o'zgarsa, shu papkadagi promptni ham yangilash kerak.**
